# DBML to Excel Extractor 🗄️

**🌍 Live Demo:** [Try the App Here](https://meta-data-extractor-mpxh88rqbvah9yxozftbin.streamlit.app/)

A lightweight, secure Streamlit web application that parses Database Markup Language (DBML) scripts—like those generated by [dbdiagram.io](https://dbdiagram.io/)—and extracts the relationship mappings into an interactive table and a cleanly formatted Excel file.

## ✨ Features

* **Intelligent DBML Parsing:** Extracts source tables, target tables, column names, data types, and primary key statuses using Regex.
* **Automatic Cardinality Mapping:** Translates DBML relationship operators (`<`, `>`, `-`, `<>`) into plain-text cardinalities (e.g., One-to-Many, Many-to-One).
* **Interactive UI:** Dynamic multi-select filters allow you to drill down into specific tables, columns, or relationship types directly in your browser.
* **Formatted Excel Export:** Downloads a polished `.xlsx` file based on your active filters, complete with:
  * Bolded headers
  * Frozen top row
  * Auto-enabled column filters
  * Auto-adjusted column widths
* **Privacy-First & Secure:** Processes everything in-memory using `io.BytesIO`. No database schemas are ever saved to the server's hard drive.

## 🛠️ Tech Stack

* **Python 3.11+**
* **Streamlit** (Frontend UI)
* **Pandas** (Data manipulation)
* **Openpyxl** (Excel formatting/export engine)

## 🚀 Running Locally

Ensure you have Python installed. You can check your version by running `python --version` in your terminal. Navigate to the project folder, install the requirements, and run `app.py` using Streamlit. Once running, open your browser and navigate to `http://localhost:8501`.

## 🔒 Security & Privacy Notes

Because database schemas can contain sensitive architectural data, this app is designed with security in mind:

* **No Disk Writes:** The Excel file is generated dynamically in RAM and served directly to the client.
* **Stateless Sessions:** Streamlit isolates user sessions; refreshing or closing the tab immediately drops the data.
